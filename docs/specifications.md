# Specifications fonctionnelles

L'application doit permettre :
- d'enregistrer une intervention ;
- de consulter les interventions ;
- d'identifier l'equipement concerne ;
- d'associer un technicien ;
- de renseigner une date.

Evolutions envisagees :
- gestion des equipements ;
- gestion des techniciens ;
- statut des interventions ;
- correction et suppression.
